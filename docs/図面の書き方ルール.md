# 図面の書き方ルール

これまでの利用者の指示から決めた、図面を生成するときの共通ルールです。新しいユニットやページを足すときも、このルールに合わせてください。

- 個々の図面を手で直さず、生成スクリプト・部品定義を直す(テンプレートを改善する)。
- 改善するときは、他のページ・他の機種にも同じルールが効くようにする(1機種だけの特別扱いを増やさない)。
- 寸法・定数は `gen_io_page.py` の先頭と `renderers/` にまとめてあり、数字はそこを参照する。

## 1. 全体
- 端子・コネクタから外側へ配線を水平に引き出す範囲は、引出し方向の配線用領域を空ける（左右分割図では、該当する半ページ内）。左向き接続点は左側、右向き接続点は右側を確保し、別機器の図、構成表示、文字、注記、設定欄などのオブジェクトを置かない。端子台だけでなく、LAN（RJ-45など）・RS-232C（D-subなど）・RS-485・USBなどの通信コネクタにも同じルールを適用する。例外としてP/N電源レールは配置してよい。構成表示や付帯欄は、配線の引出し範囲に入らない位置へ移す。
- 図枠は A3 横。PDF は QET の「PDFにエクスポート」で書き出し、`tools/pdf_to_a3.py` で上下左右の余白をそろえる。
- IO表・箱型の単体接続図は第4節の3欄見出しを使い、箱の外へ形名・機能名を重複表示しない。構成図など従来のページ見出しが必要なページだけ `page_heading()` を使う。注意書きを上部へ戻さない。
- 注記の文字は 8pt 以上。欄の中の端子番号などの小さい文字は除く。
- 注意書きは表や配線に影響しないページ最下部へまとめる。見出しとIO行の間へ注意書きを挟んだり、そのために表の途中を空けたりしない。表が下部の注意書きにかかる場合は、ページを分けて端子情報を保持する。
- 線番は 8pt で配線の上に表示する。
- 入力側のP24/N24などの電源線番は、ユニット端子の手前で右端をそろえる。中継端子を経由する場合はユニット側の導体に線番を表示し、途中の自動中央配置で位置をばらつかせない。
- 出力側のP24/N24は左のユニット端子側へ寄せ、線番の左端をそろえる。電源レーンまでの線の長さが違っても、自動中央配置で位置を変えない。
- 文字は欄・箱からはみ出さない。長い文字は折り返すか、欄に収まるまで縮める。隣の欄に掛からない余白を取る。

## 2. 配線と電源レーン
- DC 電源は P24 / N24 のレーンで表す。入出力ページ・アナログ・FX5 本体・iQ-R/Q 構成・GOT 本体(DC24V 機)で同じ位置(x=45 / 72)に置く。
- P24・N24の見出しは各レーンの真上・同じ高さにそろえる。間隔に応じて文字サイズを調整し、段違いや重なりを作らない。
- 行き先のない線(スタブ)は描かない。端子は部品として置き、配線は QET で行う。自動で引くのは電源レーンにつながる線など、行き先が決まっているものだけ。
- 接続点の黒丸は3本以上がつながる所だけ。
- 電気的な意味のない段差・短い枝線を作らない。負荷からCOMへ戻す線は1本の直角配線とし、折り返し位置にダミーの接続点を置かない。
- FX5 本体のセンサ電源(サービス電源 24V/0V)は P24/N24 につながない(容量が小さい)。
- 負荷をつなぐための COM 端子(出力ごとの COM B など)がある機種は、負荷を Y とその COM 端子の間につなぐ。COM 端子とレーンを二重に配線しない。
- コモンだけの専用ページは作らない。補助COM・IO給電端子も対応するIOページの表にまとめ、用途欄は「コモン」「外部電源」とする。手動配線の端子も表示を分離しない。
- 内部で共通でないCOMは、対応する出力との組が分かる位置に並べ、組ごとに区切る。内部で共通のCOMは、その組の下へまとめてよい。
- 用途欄には用途名だけを書く。COMは「コモン」、給電端子は「外部電源」に統一し、接続先の矢印・内部接続・配線方法・同名接続口の番号などの説明は入れない。必要な注意書きは用途欄の外へ記載する。端子名・端子番号と、利用者がCSVに入力した信号名は保持する。
- 盤内／盤外など案件ごとの境界は、任意の配線情報として細い破線と左右の表記を追加する。機種から設置場所や相手機器を推測しない。未指定の図面には追加しない。
- 送り先・相手機器・ケーブル番号・芯番号・線径・シールド・渡りなどの接続情報は、IO表の用途欄へ押し込まず、空き領域の編集可能な注記にまとめる。既存の機器やIO表を移動しない。注記の配置は指定し、頁外や追加注記同士の重なりは拒否する。生成後の注記はQETで移動できる。
- 別頁の送り・受けにはQET標準記号を使い、同じ参照IDの送り1個と受け1個を別ページに対応付ける。ページ・区画の表示はQETの標準参照を使う。接続先が分かっていない線を自動で引かず、既存端子と送り記号の導体はQETで接続する。手入力の送り先表記とは区別する。
- 明示登録された端子台名・端子番号から、両側の接続先・線番・ケーブル情報・渡りを端子台接続表にまとめられる。IO図上のコモンを別ページへ移す目的には使わない。既存IO CSVと同じ端子を登録する場合は番号・線番を一致させる。
- 任意の端子台接続図は、登録済みの端子台・端子段・端子番号を区別し、機器端子・線番・相手先・ケーブル・芯番号を独立した列にそろえる。長い内容は折り返し、行を途中で分割せず、続きのページでも列見出しを繰り返す。機器の端子やコモンは元のIO図から移さない。
- 端子の左(配線側)は配線用に空ける。端子から右に線が出る機器(FX5 の拡張ボードなど)は右も空ける。

## 3. 端子とコネクタ
- ケーブル接続のI/O図と中継端子台図は別ページに置く。双方に同じケーブル番号・ケーブル形名・両端のタグと接続口・相手ページ番号を記す。端子台は機種ごとの実端子の印字と位置を保ち、選んだケーブルを経由したPLC側ピンを対応させる。
- 端子には ○ を描く。
- 丸端子は機器枠の内側に置き、左端子は丸の左端を左枠、右端子は丸の右端を右枠に接する位置にそろえる。枠と丸の間に隙間を設けず、枠線を丸の内部へ通さない。
- 部品定義に、端子・コネクタの外へ突き出す黒い引出線を描かない。未接続時は丸端子やコネクタだけを表示する。配線用の接続ポイントは削除せず、丸やコネクタの外周に置く。接続時の導体は外周で止め、丸の内部を横切らせず隙間も空けない。QETの赤い編集用端子マーカーは部品図形の黒線とは区別する。
- 端子名は丸の機器内側へ、外周から約6pxの余白でそろえる。右側端子名は右揃えにし、短い「＋」「−」だけが丸から離れないようにする。用途説明の列とは区別する。
- PLC本体・電源ユニット・拡張ボード・通信・アナログ・リモートIOの共通端子にも同じ配置を適用する。二重接続口や同電位の内部接続線も、丸の内部を横切らせない。既存のQET図面は生成スクリプトから再生成して反映する。
- コネクタの絵は `renderers/connectors.py` の共通部品だけを使う(PLC・通信・GOT・リモートで同じ絵)。詳しくは `parts/connectors/README.md`。
  - 外形は太線の角丸、中は細線。ピンはオス黒丸、メス白丸。高さはおよそ 40。
  - ピンを端子として別に並べるときは、コネクタの絵に端子を付けない(接続点を二重にしない)。
- 通信コネクタの定義済みピン情報は、所属するコネクタの横に「ピンNo.・信号・用途」の表で表示する。文字はセルの横・縦中央に置き、長文は折り返す。NCも表示し、表に接続ポイントを重複して付けない。未確認のピン情報を追加しない。
- 部品の幅・高さ・基準点は整数にする(小数だと QET が「読み込まれなかった要素」にする)。

## 4. 記入欄・付帯情報
- 本体図で搭載されていない機能は、見出し・端子・NC・斜線を描かず、共通配置の空きスペースにする。
- 箱型の単体接続図は、箱の上端に「スロットNo.｜タグ名｜形名」の3欄を設ける。スロットを持たない機器は「ユニットNo.」にする。番号・タグは自由入力。ユニットの機能名は箱の内側の最上部へ、注意書きは配線や表を分断しないページ最下部へ配置する。
- 箱型の単体接続図（通信、GOT本体・オプション、リモートIO、FX5本体、ハブ、電源など）の3欄見出しはPLCのIO表と同じ高さ18px、上端y=34に統一する。図枠の区画番号帯（下端y=20）から14px空け、箱の本文はy=52から続ける。文字は各欄の縦中央へ配置する。単体部品を複数段に配置する場合も見出しの高さは変えない。
- NCを書くことで図が不自然になったり、余分なスペースを占有したりする場合は、NCの図示・専用行を省略してよい。接続しないことが分かるよう、資料で確認したNC端子番号を既存の下部注記に収める。NCには配線用の接続点を設けない。COMは通常の行高を保ち、端子番号と用途を明確に表示する。未確認の端子番号やNCを推測で追加しない。
- アナログのCHごとの端子は対応するCH内に置き、下部の注意書きと重ねない。コネクタごとに同じ番号を使う場合は、所属コネクタを区別する。
- IO表の上部は「スロット番号・タグ名・形名」の3欄を横並びにまとめ、その下へ列見出しとIO行を続ける。左右の表はそれぞれのユニット情報を表示する。スロット番号は自由入力し、未指定なら番号を空欄にする。
- 列見出しと最初の端子行は隙間なく続ける。その間に「入力16点 DC24V シンク/ソース」などの仕様・説明コメントを置かない。注意書き以外のコメントにも同じルールを適用する。必要な仕様・説明は表や配線に影響しないページ最下部へまとめる。
- IO表上部の情報欄・列見出しは各18pxの薄い2行とし、図枠の区画番号帯と重ねない（上端y=34、区切りy=52、IO行との境界y=70）。ピン・端子・アドレス・信号・用途などの列見出しは各セルの横・縦中央にそろえる。
- MX-RのCPU・TSN機能部・モーション部は一体のユニットとして表し、内部の縦境界2本は上端から下端まで外枠と同じ太さの点線にする。内部境界に実線を重ねず、ユニット外周は実線とする。
- RnENCPUのCPUと内蔵ネットワーク部の縦境界も、MX-Rと同じく上端から下端まで外枠と同じ太さの点線にする。
- 外部電源付き2スロット通信ユニットは、左の前半を「外部供給電源」、右の後半をネットワークの形名で表示し、中央の縦境界を外枠と同じ太さの点線にする。前半の空き16点をネットワークの信号範囲へ含めず、後半32点のアドレスとスロット番号をネットワーク部へ表示する。
- IO表内の端子番号・アドレス・信号名は各セルの横中央へ配置する。折り返して2段になる場合は2段全体を縦中央にそろえる。文字枠の余白と行数を含めて配置し、罫線への接触やはみ出しを防ぐ。
- 各部品のタグ名（図面内の管理番号）は自由入力とし、PLC1・UNIT1・AVR1などを形名と分けて表示する。空欄時は表示しない。構成ページのCPU・電源・ベース・各ユニットと、左右の通信ユニットには個別のタグを指定できる。タグを表示するために形名を削除しない。単体QET部品は編集可能な「ラベル」で管理番号を設定する。標準図にタグ欄がないPE端子も例外にせず、タグを表示できるよう補う。分岐端子のタグ・形名・定格は横配線の延長上に置かない。
- 出力の機器番号はプロジェクト内で重複させない。同じコイルを参照する入力接点には同じ機器番号を使用できる。
- 注記の改行は句読点・閉じ括弧を行頭に、開き括弧を行末に置かず、英数字の語(型式・TSN など)は途中で切らない。1〜2文字だけの行を作らない(`renderers/communication.py` の `wrap`)。
- 局番・IPアドレス・ディップスイッチなどの記入欄は図枠の左下に表で置く(`renderers/settings.py`)。
- IP 欄は Ethernet の口(RJ-45、M12 Xコード)がある機種だけ。シリアル・CC-Link・CAN・バスなどには出さない。
- iQ-R / Q の CPU の電池・SD・メモリカセット・CC-Link IE は、CPU の箱に入れず欄外の「CPUの設定/オプション」表に書く。
- FX5 本体は本体に直接配線するので、電池・USB・SD の欄を本体の箱の中に残す(iQ-R とは扱いが違う)。

## 5. iQ-R / Q 構成ページ
- 電源・CPU・スロットを実機どおり1段に、隙間なく並べる。スロット幅は 73 で固定。
- CPU は LAN 以外配線しないので幅を広げない(80)。USB(Mini-B)と RJ-45 は実機どおり縦向きの絵。
- 電源ユニットの端子は左側に、実機の端子台と同じ順に並べる。
- リモートヘッドは CPU と同じ幅・位置に置き、中身は箱の中央にそろえる。
- RnENCPUはCPU部とネットワーク部を一体で表示する。ネットワーク部はスロット0の32点を使い、内部境界の位置・線種は第4節に従う。
- 各スロットの下に先頭アドレス(16進)を書く。仮定(空き16点・アナログ16点・通信32点)は注記に書く。
- 先頭XYの指定(`module_starts`)はそのまま使い、自動で直さない。指定の無いスロットは前のスロットの次から詰める。アドレスの重複・範囲外などの割付には警告を出す。
- 各スロットのアドレス範囲は、種類説明の長さにかかわらず同じ高さへそろえる。詳細図の参照は形名とタグを照合し、タグが指定されている場合に別タグの同形名へ参照しない。相手機器の接続情報は明示入力を使い、形名から接続先を推測しない。
- 増設ベースは段ごとに下へ並べる(1ページ2段まで)。

## 6. 特殊ユニット(通信・アナログ・GOT オプション・リモートIO)
- 通信など共通枠を使う機器は、同じ枠寸法を使う（標準幅 `UNIT_BOX_W`=310、本文上端52、下端790）。下部注記のあるページは、その8px上までに箱を収める。GOTオプションの高さは第7節に従う。GOT本体など別の枠幅を持つ形式も、見出しの高さ18・上端34は共通にする。
- アナログは iQ-R も Q と同じ「端子│信号│用途」の表で描く。チャンネルは左右の半分に振り分ける。
- FX5アナログのCH枠形式も「ユニットNo.｜タグ名｜形名」の高さ18・上端y=34の見出しを付け、最初のCH枠をy=52から隙間なく続ける。FX5-8AD以外は右半ページの1列に全CH・電源端子をまとめ、P/Nレーン・注記・相手機器も右半ページ内へ配置する。FX5-8ADは左右2列に分け、両列に見出しを付ける。旧式の「形名 アナログ端子」という上部見出しは重ねて表示しない。
- アナログの方式(電圧/電流)は CSV に書けば相手機器・シールド・短絡線を描く。短絡の要否はメーカー資料で確認できた機種だけ描き、未確認の短絡線は描かず、確認状況を定義に残す。

## 7. GOT
- GOTオプションの本文枠は高さ370（上端52・下端422）と下端までの2種類。通常品は高さ370、GT01-RS4-M・GT10-9PT5Sは下端までとする。幅310・見出し18・文字とコネクタの寸法は共通のまま、注記はページ最下部に置く。
- 本体の箱は中身に合わせた大きさにし、2列(左: 電源・シリアル・Ethernet、右: USB・HDMI・SD・バッテリ)に並べる。
- Ethernetのコネクタ枠を区切り線や機器の下枠に接触・重複させない。上下の段の間隔はコネクタ共通の領域高さで確保し、コネクタ外形の下に10px以上の余白を残す。
- 接地2端子は左から LG・FG で、短絡して接地する。1端子の機種は FG。
- 外部配線のないオプション（変換器など）は接続点を付けず、そう書く。

- インバータ・GOT本体の右側に配置するコネクタは、名称を左、コネクタの絵を右枠寄りに置く。絵は正面図のままとし、接続点はコネクタの右端・右向きにする。左側に配置するものは従来どおりとし、未接続時の引出線は描かない。

- MX-FのIO表は実物の端子記号とPLCアドレスを区別する。メーカーが付けていない端子番号を作らず、入力電圧・出力形式・出力用外部電源を表上部に短く示す。本体図と内蔵IO図は同一タグを使う。拡張アダプタは左、専用増設IOは右に構成を示す。

## 8. 資料と推測
- 標準記号のコイル・オンディレイコイル・操作スイッチ（master）は形名・定格をタグ上に配置し、タグ下をQETの自動接点参照の領域として空ける。標準記号の図形・接続点は変更しない。
- 端子番号・端子名・配線方法はメーカー資料で確認し、出典(文書番号・章・ページ)を定義に書く。
- 資料で確認できないことは推測で描かない。確認状況は定義に残し、図面には「未確認」「要確認」等を表示しない。

## 9. 確認のしかた
- 変更が影響する形名を生成してエラーがないか確かめ、簡易プレビュー(`tools/preview_qet.py`)で見る。最終確認は QET の PDF。
- 自動テストを回し、増えた失敗がないことを確かめる。レイアウトを変えたときは、古いレイアウトを前提にしたテストを新しいルールに合わせて直す。

### 電源単体部品の大きさ

入力側・出力側とも接続端子が5点以下で通信コネクタがない電源は、箱幅240を保ち、箱の高さを300から150へ半減する。見出しは共通の18。文字を一律縮小せず、端子間隔と入力電圧の位置を詰める。6点以上の端子列、Ethernet付き電源、S8AS2の分岐電源は従来の枠を使い、端子やコネクタを省略しない。

電源の右側端子名は固定幅欄の右揃えとする。文字幅の概算で開始位置を動かさず、＋/−、CH番号、警報端子等の右端を端子手前の同じ位置に合わせる。

### ハブ単体部品の大きさ

5ポート以下のハブは電源・接地・警報の端子数に合わせて上段を詰め、最終LANポートの下10pxを空けて下部欄へ続ける。箱幅260とRJ-45の50px間隔は維持する。登録済み5ポート品は高さ540、二重電源・警報付きは600。8ポート品は高さ750を維持し、端子・ポート・DIP欄を省略しない。

### シリアルコネクタと短絡片

- RS-232C・RS-422/485のD-sub 9ピンには、機種別のピン番号・信号名の表を付ける。NCも記載する。共用ポートは選択した通信方式の配列を表示する。
- インバータの出荷時に付く短絡片・短絡用電線は、確認できた端子間に接続する。「短絡片」の表記は同じ端子群につき1か所とし、端子の近くに置く。P/+–P1の表記はP/+側に寄せ、PRからの配線延長方向を空ける。外部の安全回路は自動配線しない。
