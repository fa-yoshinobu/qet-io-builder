# オムロン NX のユニット図

## GUIで生成する

`GUI起動.bat` のメニューで「オムロン NX・NA」を選び、シリーズを「NX」にします。「形名・機能で絞り込み」で対象を探し、ユニット形名を選んで「ユニット図面を生成（.qet）」から保存します。ユニットNo.とタグ名は任意です。生成したQETをQElectroTechで開き、用途や接続先を記入して配線します。

NA5タッチパネルの対応範囲と操作は、[タッチパネルの本体接続図](タッチパネル.md) を参照してください。

## 作図の扱い

入出力の用途・接続先・センサ・負荷は、生成後のQETで記入・接続します。端子・信号名はメーカーの端子配列に従い、同じ番号を使うコネクタは所属を区別します。独立するCOMは対応する入出力との組を保ちます。端子番号のない端子には番号を追加しません。

外部入力用のDC24Vユニット電源はP24/N24へ接続します。I/O電源は使用機器の電圧・供給系統に合わせてQETで接続します。ユニット電源、I/O電源、出力COMを一括で短絡しません。NX-PC系はNXバスからのI/O電源を外部機器へ接続する用途で、外部から電源を入力しません。
