# タッチパネルの本体接続図

## GUIで生成する

`GUI起動.bat` を起動し、メーカーのメニューからシリーズと形名を選びます。

| メニュー | 選ぶシリーズ |
|---|---|
| キーエンス KV・VT | VT3 または VT5 |
| オムロン NX・NA | NA5 |

ユニットNo.とタグ名は任意です。「ユニット図面を生成（.qet）」で保存し、QElectroTechで開いて接続先と配線を仕上げます。

## 電源・ポートの扱い

- VT3のAC電源機種はAC100～240Vの入力2端子とPEを保持します。VT3・VT5・NA5のDC24V直接入力端子はP24/N24へ接続します。AC端子やシリアルの電源出力はP24/N24へ自動接続しません。
- USBは物理的な口数を残します。VT3はType-Bを1口、VT5標準はType-Aを2口・Mini-Bを1口・Type-Bを1口、VT5-WXはType-Aを4口、NA5はType-Aを2口・Type-Bを1口描きます。VT5標準の前面Type-A・前面Mini-B・背面Type-Bは同時使用できず、背面Type-Aは独立です。
- VT5-WXにはCOM端子を追加しません。パワーコントロール端子はそれぞれの用途を保持し、電源入力と一括接続しません。
- NA5の-V1金属筐体は、電源コネクタのFGとは別に独立PE端子を描きます。-V1-Pの同じねじ位置はPE機能がないため注記だけとし、-V2には独立PE端子を描きません。
- VT3のPORT3ピン9とNA5のシリアルピン6はDC5V出力です。相手機器の給電条件に従って接続します。シリアルのNCもピン表に残し、NCへ配線用の接続点を追加しません。
- VT3のハンディ型は専用ケーブル／本体接続ケーブル経由で給電します。ケーブルの形式と通信方式に合わせて端子表・下部注記を使い、ケーブルのFGも接地します。
