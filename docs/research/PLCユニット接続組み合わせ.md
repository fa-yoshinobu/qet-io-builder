# キーエンスとオムロンのPLCユニット接続組み合わせ

現在の機種別定義にあるキーエンスKV・オムロンNXを対象に、CPUへ装着できるユニットと接続条件を整理する。三菱、NJ、セーフティは対象外。接続表の「可」は、台数・電源容量・CPU版・ユニット版・設定ソフト版の条件を満たす場合を指す。

## 形名ごとの接続表

| 対象 | 一覧の内容 |
|---|---|
| [KV-7000・KV-8000・KV-X500](キーエンスKV接続組み合わせ.md) | KV-7500/7300/8000/8000A/X500/X520/X530/X550と拡張ユニットの対応。直接装着、KV-7000C経由、専用電源、EtherCAT経由を区別 |
| [KV Nano](キーエンスKVNano接続組み合わせ.md) | N14/N24/N40/N60/NC32Tと各拡張。N1/NC1によるバス変換、前面カセット、左側アダプタ、EP02/EC01配下を区別 |
| [オムロンNX](オムロンNX接続組み合わせ.md) | NX701/502/102/1P2とNXユニット。NXバス、NX502のXバス、EtherCAT/EtherNet/IPカプラ配下を区別 |

各一覧の出典表に、資料名・文書番号・章・印刷頁・PDF照合頁を記載する。拡張の成立に必要な変換器・給電ユニットは、現在の作図登録の有無にかかわらず接続条件に含める。

## 基本構成と上限

| CPU | 装着する場所・経路 | 台数・給電の基本条件 | 根拠 |
|---|---|---|---|
| KV-7500/7300、KV-8000/8000A、KV-X500/X520/X530/X550 | 高速バス用ユニットはCPU右側。旧KV-5000/3000系はKV-7000C経由 | 高速バス用は第1段16台以内。新旧混在の合計48台以内、各段16台以内。個別台数と電源容量も適用 | KV詳細表の中核資料A/B/C 第1章・第3章 |
| KV Nano N14系 | 右側I/O列、前面カセット | 右側3台・追加I/O128点以内。NC1EPは不可 | Nano詳細表 S1 1-1・S4 1-3 |
| KV Nano N24/N40/N60系 | 右側I/O列、前面カセット | 右側8台・追加I/O256点以内。NC1EPはN1経由、CPU機能Ver.2以降 | Nano詳細表 S1 1-1・S4 2-2 |
| KV-NC32T | 右側コネクタバス、左側NC10L/NC20L | 右側8台・追加I/O256点以内。端子台側拡張にはNC1が必要 | Nano詳細表 S2 1-1・2-8 |
| NX701 | ローカルNX増設なし。NXユニットはカプラ経由 | CPUラックはNX-PA9001またはNX-PD7001＋CPU。リモート側の給電は別に設計 | NX詳細表 R1 1-9・2-2～2-3 |
| NX502 | **左側Xバス、右側NXバス** | **左は最大4台・50W、右は最大63台・内部電源10W**。CPU端子へDC24Vを入力し、I/O電源は右側PFへ別途供給 | NX詳細表 R2 2-2～2-6・4-2～4-9 |
| NX102 | 右側NXバス | 最大32台・内部電源10W。I/O電源は別途供給 | NX詳細表 R3 2-2～2-5・4-2～4-3 |
| NX1P2 | 右側NXバス、別枠のオプションボード | NXユニット最大8台・内部電源10W。NXバスI/O電源は最大4A | NX詳細表 R4 2-2～2-5・4-3、R8 4-34 |

KVの「高速バス用」は、詳細表のD群を指す。KV-B/CシリーズI/Oなどの旧ユニットを、名前だけで高速バス用と判定しない。Nanoの「端子台タイプ／コネクタタイプ」は拡張バスの方式であり、外部端子がヨーロピアン端子台かどうかとは別である。

NX502はCPU本体の端子台から給電する。NX701用のNX-PA9001/PD7001を、NX502の左側電源ユニットとして扱わない。電源追加供給ユニットを追加しても、NXバスの装着台数上限は増えない。

## 単純なシリーズ選択では判定できない組み合わせ

| 組み合わせ | 判定・条件 | 根拠 |
|---|---|---|
| KV-B/CシリーズI/O・旧アナログなど＋大型KV CPU | KV-7000Cとエンドユニットが必要。CPUへ直接つなぐD群とは別 | KV詳細表のC群 |
| KV-N14系＋KV-NC1EP | 不可。KV-N1を追加しても対象CPUにならない | Nano詳細表 S4 巻頭21・1-9 |
| KV-EC01＋CPU | CPU横のローカル拡張ではなくEtherCAT上の別ステーション。内蔵マスタはKV-X520/X530/X550にあり、KV-X500にはPORT3がない | KV詳細表 E、基本UM084914 2-7～2-8 |
| NX-EIP201＋CPU | NX502の**左側Xバス専用**。右側NXバスやカプラ配下には装着しない | NX詳細表 R5 A-25・R9 |
| NX-ECT101＋CPU | CPU側NXバスのユニット。カプラ配下は不可。NX502は更新後の共通対応表とCPU構成を組み合わせた判定 | NX詳細表 ※E・R5 A-24/A-34/A-44 |
| NX-HAD401/402、NX-PG各機種、NX-ID3344/3444、NX-OD2154/2258＋NX-EIC202 | EIC202配下では不可。EtherCATカプラの対応をEtherNet/IPカプラへ流用しない | NX詳細表 R5 A-36・A-38・A-40 |

## 適用を確定できない条件

| 対象 | 相違・不足と扱い |
|---|---|
| KV-SC20V＋KV-X500系 | 基本UM084914 付-25は使用可、置き換えガイド084956 p.5は不可。両資料の版記号が2045-1であり、適用判断は保留 |
| KV-XH32EC/16ECの最大台数 | 個別UM084972の1-18と2-5で台数が不一致。CPUへの接続可否・必要版と、最大台数の未確定を分ける |
| EP02＋NC32EXE/NC32ETE/NC16EXTE | 手元のEP02対応表に形名がない。EC01の対応を流用して可とはしない |
| EP02を8000/Xから制御する場合の占有上限 | 手元EP02資料の15/8スロット区分に新CPUが明記されていない |
| EC01＋XH16EC/32EC/64EC | XH EC側の汎用I/O機能は確認できるが、この具体的組み合わせの明記は未確認 |
| NX-CTのEIC202最古版 | 専用UMのユニット側表と、NX CPUからのカプラ接続条件を併せて判断する。1.0構成を単独で可としない |

この資料は接続条件の整理であり、機種JSON・GUI・作図処理の接続可否検査には反映していない。作図できる形名であることと、そのCPUに接続できることは別に扱う。
