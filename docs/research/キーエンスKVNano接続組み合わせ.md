# KV NanoのCPUとユニットの接続組み合わせ

対象は登録済みKV Nano基本ユニット22形名、同区分の非CPU38形名、およびKV-EC01。NC4ADG/NC4DAG/NC8ADGは対象外。これは接続条件の調査であり、図面・機種定義・GUIの変更を含まない。PDF頁は表紙を1とする。

## 1. CPU別の接続上限

「端子台タイプ／コネクタタイプ」は拡張バスの接続方式を指す。外部I/Oがヨーロピアン端子台のKV-NC…Eも、接続バスはコネクタ側であり、ネジ端子台型のKV-N…とは区別する。

| 基本ユニット（登録形名を全列挙） | 右側の拡張台数／追加I/O点数 | 前面・左側の増設 | KV-NC1EP | 根拠 |
|---|---|---|---|---|
| KV-N14AR / KV-N14AT / KV-N14ATP / KV-N14DR / KV-N14DT / KV-N14DTP | 合計3台まで／128点。基本ユニット内蔵I/Oは点数に含めない | N10L/N11Lは前面1台まで。N1AWは前面1台まで | **不可**。N1を挟んでも対象CPUに含まれない | S1 1-1 印刷1-2～1-4、2-1 印刷2-3／PDF20～22、31。S4 巻頭印刷21、1-3 印刷1-9／PDF23、33 |
| KV-N24AR / KV-N24AT / KV-N24ATP / KV-N24DR / KV-N24DT / KV-N24DTP | 合計8台まで／256点。内蔵I/Oは除外 | N10L/N11Lは前面1台まで。N1AWは前面1台まで | N1経由、CPU機能Ver.2以降 | S1 同上。S4 同上、2-2 印刷2-7～2-8／PDF43～44 |
| KV-N40AR / KV-N40AT / KV-N40ATP / KV-N40DR / KV-N40DT / KV-N40DTP | 合計8台まで／256点。内蔵I/Oは除外 | N10L/N11Lは前面2台まで。N1AWは1台まで | N1経由、CPU機能Ver.2以降 | S1 1-1 印刷1-2～1-4／PDF20～22。S4 巻頭印刷21、1-3 印刷1-9／PDF23、33 |
| KV-N60AR / KV-N60AT / KV-N60ATP | 合計8台まで／256点。内蔵I/Oは除外 | N10L/N11Lは前面2台まで。N1AWは1台まで | N1経由、CPU機能Ver.2以降 | S1・S4 同上 |

R/T/TPによる内蔵出力方式の差を、右側拡張の接続可否の差へ読み替えていない。AC/DC電源差は第4節の給電枠へ適用する。前面カセットは右側拡張ユニットとは別の取付系統である。N14/N24は前面ソケット1個、N40/N60は2個のため、シリアルとN1AWの併用時も物理ソケット数を越えられない（S1 2-2 印刷2-6～2-7／PDF34～35の本体図と1-1 印刷1-3／PDF21）。N1AWを2個装着しても動作しないことは明記されている。

## 4. 台数・点数・電流の判定を分ける

| 給電元・構成 | 台数／占有スロット | 点数・消費電流の条件 | 根拠 |
|---|---|---|---|
| N14系 | 右側拡張3台まで。変換器は数えない | 追加I/O最大128点。AC機は拡張給電＋サービス電源の合計を0.6A以内。DC機の基本ユニット給電枠は2A | S1 1-1 印刷1-2、1-7、2-1 印刷2-3／PDF20、25、31 |
| N24/N40/N60系 | 右側拡張8台まで。変換器は数えない | 追加I/O最大256点。AC機は拡張給電＋サービス電源の合計を0.6A以内。DC機の基本ユニット給電枠は2A（登録N60はAC機のみ） | S1 同上 |
| NC32T | 右側拡張8台まで。変換器は数えない | 追加I/O最大256点。基本ユニット給電枠は1.5A | S2 1-1 印刷1-2、1-7、2-1 印刷2-3／PDF20、25、31 |
| EP02：上位スキャナがKV-7000/5000/3000系 | デジタル各1、アナログ・温度各2、変換器0。占有合計15以下（アナログだけなら7台） | EP02を含む最大消費電流の合計1.8A以内。EP02自身の内部電流120mA以下を加算 | S5 2-1 印刷2-2、3-1 印刷3-2～3-3／PDF20、30～31 |

| EC01 | 対応デジタル・アナログ・温度すべて各1、変換器0。占有合計15以下 | EC01を含む最大消費電流の合計1.8A以内。EC01自身の内部電流120mA以下を加算 | S6 2-1 印刷2-2、3-1 印刷3-2～3-3／PDF18、26～27 |

設計時は各ユニットの仕様表にある「内部消費電流」の最大値を使う。AC機ではサービス電源の使用分も同じ枠から差し引く。台数だけを満たしても給電可能とは限らない。例えばN3AMは120mA以下なので6台で最大720mAとなり、AC基本ユニットの0.6A枠を超える（S3 3-3 印刷3-4／PDF36の仕様、S1 印刷1-7／PDF25）。

電流値の照合先は、端子台I/OがS1 2-7～2-9 印刷2-48、2-52、2-57／PDF76、80、85、コネクタ側I/OがS2 2-4～2-6 印刷2-19、2-25、2-34／PDF47、53、62、アナログ・温度がS3およびS8仕様表。NC1EPはS4 1-3 印刷1-9／PDF33。古い拡張I/O取扱説明書のNC32ET(P)消費電流30mAと、S2の50mAに差があるため、上限計算では新しいS2の50mAを採る。NC32ETEもS2では50mAである。

## 6. 組合せを確定する前に残る項目

| 項目 | 現状と扱い |
|---|---|
| EP02＋NC32EXE/NC32ETE/NC16EXTE | S5 3-3の列挙にない。EC01で対応明記されたことをEP02に流用しない。追加の公式対応根拠が必要 |
| EP02＋KV-8000/KV-X系を上位スキャナにした場合の15/8区分 | S5の15スロット条件はKV-7000/5000/3000系を列挙する。新しいCPUを自動で同じ区分に含めない。Nano＋NC1EPでは8と確定 |
| CPU追加I/O点数128/256の混在換算 | 数値自体と内蔵I/O除外は明記。入力＋出力の合算方法や、アナログ占有リレーを点数へ換算する詳細は今回の該当箇所だけでは未確定。NC32EXTのような入出力混在型を単に「32点」とせず、仕様の32入力＋32出力を保持する |
| NC1EPの固有最大装着台数・CPU占有数 | 対応CPU・経路・FWは確定。S4の照合箇所ではNC1EP固有の複数装着上限・CPU上の占有数の明文を未特定。CPU右側の共通上限8だけから固有上限を断定しない |
| 各カセットの内部消費電流 | 本文・取説の確認箇所に個別値の記載を特定できていない。値0とせず、必要な給電計算が確定するまで未確定とする |
