# 機種別の設定欄一覧

通信・機器設定の記入欄を、機種ごとに整理した一覧です。本体・通信ページはUIと図面に反映済みです。ハブ・電源など単体部品の書出しは検討中の表示案を含みます。機種の全機能を列挙する資料ではありません。

## 共通の4分類

| 記号 | 表示名 | 記入内容 |
|---|---|---|
| N | 局番・ネットワーク番号 | 局番、ネットワークNo.、ノードID、バス上のアドレスなど。該当する名称を添えて自由記述。 |
| I | IP設定 | 使用ポートごとのIPアドレス。必要ならマスク・GW・ポート番号を同じ欄に追記。 |
| C | 通信設定 | CH、プロトコル、通信速度、データ長・パリティ・ストップビットなど。 |
| S | 機器設定 | モード、DIP/ロータリーSW位置、終端抵抗、QoS/BSP、応答時間、HOLD/CLEAR等。 |

- 「基本候補」はその接続方式で通常使う欄。「追加候補」は使用する機能と案件に応じて選ぶ欄で、常時全枠を出す意味ではありません。
- 「—」は通信設定欄の指定なし。機器自体に設定機能がないと断定する意味ではありません。
- 図面は既存の8pt程度を基準に、項目名と値を同じ行へ配置。未使用の大きな枠は作らず、必要な欄だけを印字します。
- DIPの有無・ビット数ごとの専用フォームは増やしません。DIP、ロータリー、画面/ソフトによる設定を、同じ意味の設定値として記録します。
- RJ-45の絵だけでIP欄を決めません。光のTSNにもIPがあり、アンマネージドハブには管理用IP欄がありません。
- CPUの電池・バッテリレス・SD・SRAM、形名・タグ・スロット、端子やIO/CH情報は既存欄を使い、この一覧では重複追加しません。
- 「表示案」は記入欄の提案で、全機種の全スイッチを実機確認した印ではありません。「条件付き」「保留」は固定表示を確定する前に接続方式・個別資料の確認が必要です。

## 表示・非表示の操作

- Web版はページ設定の「通信・機器設定」でチェックを切り替えます。Tk版は各欄の「表示」チェックを使います。
- 非表示にしても入力値を保存し、再表示で戻します。項目削除の操作は設けません。図面には非表示の項目名・値・枠を出しません。
- 保存キーは `settings_visibility`。左右の設定は `left_ip` / `right_ip` 等の別キーで管理します。旧 `dip` の値は「機器設定」として保持します。
- 機種別の初期表示・候補は `parts/settings_fields.toml` で管理します。定義を変更した場合はGUIを再起動してください。
- NZ2GNはTSN用のN・Iを初期表示とします。Fieldで使用するときはIP設定を非表示にします。GOTハンディは接続方式に合わせてIP設定または通信設定を表示します。保留機種は基本欄を自動表示しません。

## 追加機種

- CC-Linkの追加アナログ・パルスは局番・通信設定を基本とし、機器設定は任意です。AJ65SBT2B-64AD/64DAは通信速度の自動追従仕様です。
- ER-1FL2-T / QJ71FL71-T-F01は局番（ノード番号）・IP設定を基本とし、通信設定・機器設定は任意です。
- MX-R / MX-Fは局番・IP設定を基本とし、通信設定・機器設定は任意です。MX-FのEtherCAT仕様はP1がEtherCAT、P2がEthernetです。

## 特に扱いを分けるもの

- QJ61BT11Nの局番・伝送速度/モードは前面ロータリースイッチ、RJ61BT11はユニットパラメータで設定します。表示内容はN/Cで共通にし、スイッチ番号等の記録が必要なときだけSを使います。根拠：FA-D-0171-B p92。
- GOTにも終端抵抗切替スイッチを備える機種・通信ユニットがあります。「GOTだからDIPなし」と一括判定しません。終端条件はSへ記入します。根拠：SH-081200ENG-AS p53–54ほか。
- NZ2GN系はTSN/Fieldの通信モードで判断します。現行JSONのnetworkにはField表記のものもあるため、その文字列をそのまま固定表示判定へ使わない方針です。根拠：SH-082239-L 7.1（印刷121–123）、SH-082235-F・SH-082237-F。
- GT2505HS-VTBD/GT2506HS-VTBDは専用ケーブル経由の通信です。外観にRJ-45がないことだけではIP欄を除外しません。
- B-RIF、RJ51AW12AL、GT25-FNADPは、局番と配下アドレス、搭載モジュールの設定の区別を再確認するまでN/Cの固定表示を保留します。
