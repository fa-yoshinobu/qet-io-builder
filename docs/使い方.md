# 使い方

[README](../README.md) / [設定ファイル](設定ファイル.md) / [開発・保守](開発・保守.md)

## 必要なもの

- Python 3.11以上。画面には pywebview を使う（`GUI起動.bat` が初回に `pip install pywebview` を行う）。
- QElectroTech。生成したQETの編集・表示確認・PDF書出しに使う。
- PDFのA3調整にはpypdf。Ghostscriptがあれば図面の範囲を測って配置する。

## GUIで図面を作る

1. リポジトリの `GUI起動.bat` を起動し、最初のメニューで「PLC・GOT の図面を作る」の「新しく作る」か「プロジェクトを開く」を選ぶ。メニューには「制御部品の書出し・ユーザーコレクション登録」「a・b接点の参照表を更新」もあり、画面左上の「≡ メニュー」でいつでも戻れる。
2. 左の「ページ追加」でページを作り、メーカー → シリーズ → 図面の種類を選ぶ。既存JSONを開いた場合は形名からメーカー・シリーズを表示する。
3. 形名は「選択」から一覧で選ぶ。一覧は種類で絞り込め、形名・仕様で検索できる。
4. 左の「プロジェクト設定」で図面情報、P/N電源、表紙の有無を入力する。
5. 「保存」してから「図面生成（.qet）」を押す。「構成チェック」は保存せずに生成と同じ検査を行う。FX5本体・混合入出力のページでは「CSV雛形」で予備を入れたJSONとCSVを作れる。
6. 生成したQETをQElectroTechで開き、配線を仕上げる。

画面は3列で、左がページ一覧、中央が選んだページ、右が選んだ項目の設定と操作。設定はすぐ反映され、「保存」でJSONに書く。ページの順番は、左の一覧をドラッグして入れ替える（ページ上部の ↑ ↓ でも動かせる）。

左のページ一覧は、形名・タグ・スロット番号から構成図と詳細ページを親子表示し、「詳細 ○ページ」で開閉できる。表示のグループ化では図面のページ順を変えない。

「元に戻す」「やり直す」でページ・ユニット・タグ・XY・配線設定などの変更を最大100操作戻せる。一括ページ作成は1操作として扱う。Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z）でも操作でき、文字入力中は入力欄自身の取り消しを優先する。別のプロジェクトを開く・新規作成・アプリ終了で履歴は消える。取り消す対象はプロジェクト設定で、作成済みCSV・QET・部品ファイルや保存済みJSONは削除・巻き戻ししない。取り消した状態をファイルへ反映するには保存する。

### キーエンスKV・オムロンNXの構成

1. メーカーのメニューで「PLC構成」を選び、シリーズを指定して「構成を新しく作る」を押す。
2. 使用するCPUまたはリモートI/Oのカプラを選ぶと、その本体の接続位置が表示される。タグは形名と別に入力する。
3. 接続する位置の「追加」でユニットを選ぶ。CPUに対応する候補だけを表示し、追加時に台数・バスの並び・機能バージョンの条件を検査する。NX502は左Xバスと右NXバス、Nanoは左右・前面を区別する。必要なKV-7000C・KV-N1・KV-NC1は構成へ自動表示する。
4. KV-N11L・KV-NC20Lは追加時に通信方式を選ぶ。KV-NC20Lの選択はPORT2に適用される。構成上のユニットを選択すると、あとから方式を変更できる。
5. 「構成図＋詳細図を生成」でQETの保存先を選ぶ。作成済みの詳細ページはそのまま使い、不足分には構成のタグ・ユニット番号・通信方式を引き継ぐ。装着順だけを出力するときは「構成図のみ」を選ぶ。
6. 後日構成を編集するには「保存」でJSONを保存し、同じメーカーの「構成を開く」から再開する。

単品を出力する場合は「ユニット単体図」または「タッチパネル図」を選ぶ。どちらのメーカーでも、形名の一部や機能名で候補を絞り込める。

構成図は装着順を示す概要図で、端子への電気配線は詳細図で扱う。カプラ配下はカプラを本体にした別の構成ページにする。通信ケーブル経由の接続先は自動で推測しない。

必要な電源ユニットやI/O電源追加供給ユニットが不足した構成は編集途中のまま保存できるが、詳細ページの一括作成・図面生成は不足理由を表示して止める。機能バージョンを入力した場合は最低版を検査し、未入力の場合は条件を表示する。各給電ブロックの消費電力・I/O電流・電圧降下・データ量は、画面の条件と[接続組み合わせ資料](research/PLCユニット接続組み合わせ.md)を使って確認する。

KV-7000/8000/Xの増設段指定は未対応のため、現在の画面から生成できるのは直接接続の16台以内。KV-X300系、NJ、セーフティ、資料不足で除外した形名は選択肢に含めない。VT・NAは単体図の生成を使う。

### CC-Linkアナログ・パルス／MXコントローラ

- CC-Linkリモートは「リモートIO 本体・通信」と「リモート アナログ入出力」または「CC-Link パルス・位置決め」を使います。通信・電源は箱型、信号端子は従来IOと同じ連続した表です。
- MELSEC MX-Rは「iQ-R / MX-R 本体・ユニット構成」を使います。Rシリーズの電源・ベース・対応確認済みユニットを選択でき、内蔵機能部の2スロット／64点を先に割り付けます。
- MELSEC MX-Fは「MX-F 本体」と「MX-F 入出力」を使います。EtherCAT仕様は形名末尾`-EC`で区別します。MX-F専用IOは同じシリーズから選択します。本体をクリックして「内蔵IOページを開く・作成」を使うと、本体のタグとユニット番号を引き継ぎます。
- MX-F本体の内蔵I/OはX00～X0F・Y00～Y0F固定です。増設IOの開始アドレスは16進数です。パルス・MX-F IOの「IO CSV作成」でBOM付きUTF-8の雛形を作成し、Excelで「用途」を編集できます。`No.`は端子行の識別用なので変更しません。端子名・信号名は機種定義を使用します。
- コモン・外部電源は同じ端子表に残します。未使用の実端子も表示し、NCには接続点を設けません。外部配線はQETで仕上げます。

### ユニット構成（iQ-R・MX-R・Q・FX5本体）

本体ページでは中央にベースの図を出す。スロットの上にスロット番号と先頭アドレス、下に形名・仕様・タグを表示する。

- 電源・CPU・ベース名をクリックすると、右側で形名の選択やCPUの装着品（電池・SD・メモリ）を設定できる。
- 空きスロットを選んで「ユニットを追加」を押すと選定画面が開く。選んだユニットはそのスロットに入る。2スロットのユニットは右隣を空けておく。
- 入ったユニットを選ぶと、タグ名の入力、先頭XYの指定、ユニット変更、取り外しができる。「＋ ○○ページを作成」で、そのユニットの端子図・接続図のページを形名・タグ・スロット番号を入れて追加する。既にあるページは「→」で開ける。
- 「増設ベース追加」で増設ベースと電源を選ぶ。増設段のスロットも同じ操作でユニットを置ける。
- FX5本体は本体の右に増設ユニットを並べ、「＋ 追加」で増やす。
- iQ-R・Qでは各ベースの下の「スロット一覧」で形名・タグ名・先頭XYを編集できる。空欄の先頭XYは自動割付。2スロット占有部やCPU一体のネットワーク部は編集できない。
- XY警告の「スロット○へ」を押すと対象を選択し、右側の先頭XY欄へ移動する。重複する2スロットにはそれぞれ移動ボタンが出る。CPU設定は「管理番号」「バッテリ」「SD・カセット」「拡張ボード」に分け、機種に必要な欄だけを表示する。

### 構成から入出力のページを作る

「構成との比較」で、構成と詳細ページの形名・タグ・番号・先頭XYの差分を一覧にする。ページ名のボタンで対象へ移動でき、チェックした詳細だけを構成に合わせられる。曖昧な対応やページ種類が合わない場合は修正対象にできない。変更は「元に戻す」に対応し、CSVの信号名・アドレス等は書き換えない。先頭XYを合わせた後はCSVのアドレスを確認する。

CSV欄の「開く」は、プロジェクトJSONを基準にファイルを探し、CSVに関連付けられたアプリ（通常Excel）で開く。Excelで保存した後の「CSV再チェック」は、ファイルを読み直して生成と同じ検査を行う。CSVは自動修正しない。

1. 本体ページのベースの図にユニットを置き、タグ名を入れる。
2. ページ上部の「詳細ページを一括作成」を押す。まだページが無いユニットごとに、形名・タグ・スロット番号・先頭アドレス（構成図と同じ割付）を入れたページを作る。通信ユニットは接続図、構成図だけのユニットは作らない。
3. 「ページとCSVを作成」を選ぶと、アドレスを入れた入出力CSV（信号名は空欄）とアナログCSV（CHだけ）をプロジェクトと同じフォルダに作る。既にあるファイルは上書きせずにそのまま指定する。1ページずつ作るときは、各ページの「CSVを作成」を使う。
4. CSVをExcelで開いて信号名・機器番号などを入れ、「図面生成」を押す。

### 先頭XYの指定

先頭XYは空欄なら自動で、前のスロットの次から詰めて割り付ける。ユニットを選んで右側の「先頭XY（16進）」に入れると、そのスロットはその値になり、以降の自動のスロットは続きから割り付く。指定したアドレスは図の上で色を変えて表示する。

16点単位でない、他のスロットと重なる、CPUの入出力点数を超える、入出力ページの先頭アドレスが構成と違う、のいずれかに当たると「XY割付の警告」を出す。値は自動で直さない。図面生成・構成チェックでも同じ警告を表示し、図面は指定どおりに作る。

入出力・混合ユニットのページはCSVが無くても生成でき、アドレスだけの図面（用途欄は空欄）になる。ユニットを後から別のスロットへ動かした場合、ページの先頭アドレスとCSVのアドレスは自動では直らない（ずれると警告が出る）ので、ページの「先頭アドレス」とCSVを合わせる。

FX5の本体図は「本体・拡張ボード」を選ぶ。

JSON保存は成功時だけ既存ファイルを置き換える。種類を選んでいないページがあると保存しない。機種変更で非対応になったオプションは保存対象から外す。CPU一体のネットワーク部もスロット使用数に含める。画面のコードを変更した場合は再起動して使う。旧画面（tkinter）は `python gui.py` で起動できる。

### CPUの装着品・増設上限

CPUを選ぶと容量・I/O点数・搭載機能・増設上限を表示し、電池・SDカード・メモリの選択肢を切り替える。Q・iQ-Rの「本体・ユニット構成」を選ぶと、ベースの選択画面だけが開く。CPUと電源はベースの図でクリックして選ぶ。

装着品はCPUに対応する型式から選ぶ。SDカードは自由入力もできる。状態が「有」の装着品を構成図へ表示し、増設段数・合計スロット数は生成時に検査する。

対応型式は [Qの対応一覧](../parts/plc/mitsubishi/q/対応ユニット一覧.md)・[iQ-Rの対応一覧](../parts/plc/mitsubishi/iq_r/対応ユニット一覧.md)、詳しい条件は [Q CPUの選択仕様](research/q_cpu_selection.md)・[CPUのオプションメモリ](research/cpu_memory_options.md) を参照する。

### タグ・配線情報

「タグ名（管理番号）」は `PLC1`・`UNIT1`・`AVR1` などの自由入力で、形名・ページ名とは分けて扱う。空欄なら表示しない。電源・ベース・拡張ボード、左右の通信ユニットにも個別に指定できる。各スロットはベースの図で選び、右側のタグ名に入力する。単体部品はQETの「ラベル」、番号は「補助情報1（auxiliary1）」で編集する。

選択ページの「配線情報」で、盤内外境界・接続先・ケーブル情報・送り受け・端子段を登録する。「端子台接続図を追加」を選ぶと、登録済みの外部端子台を本文末尾の表へまとめる。配置やJSON項目、接続表CSVの仕様は [設定ファイル](設定ファイル.md) の「配線情報・端子台接続表」を参照する。

## コマンドで生成する

リポジトリのフォルダで実行する。

```console
python gen_io_page.py project.json 出力.qet
```

CSVなどの相対パスはプロジェクトJSONの場所が基準。再生成するとQETを作り直すため、QETで手直しした内容は上書きされる。入力形式は [設定ファイル](設定ファイル.md) を参照する。

## 部品を書き出す

メニューの「制御部品の書出し・ユーザーコレクション登録」で専用の画面を開き、一覧から選ぶ（メーカー・種類で絞り込み、検索可）。補助接点・動作構成がある機器は右側で選び、「書き出す…」で書出し先を指定すると、QETに手で置く部品（`.elmt`）を作る。標準記号を使う機器はQET標準コレクションを使用する。

Windowsでは、部品を選んで「QETに登録」を押すと、保存先を選ばずユーザーコレクションへ直接登録できる。QETに設定済みのユーザーコレクションを優先し、標準では `%APPDATA%/QElectroTech/QElectroTech/elements`（旧形式は `%APPDATA%/qet/elements`）を使う。「qet-io-builder → メーカー → シリーズ → 形名 → 構成」の順に整理し、同じ形名・構成の再登録は生成部品を更新する。このフォルダー内の部品をQETで手直しした場合は、再登録で上書きされるため、別の場所へ複製して使う。登録後はQETのユーザーコレクションを更新するかQETを再起動する。ポータブル版など独自のデータディレクトリを指定している環境では「書き出す…」で保存先を指定する。従来のTk版にも「QETに登録」ボタンがある。

「全部QETに登録」は検索・絞り込みに関係なく、全メーカーの登録済み制御部品を一括登録する。補助接点・動作構成に複数の選択肢がある機種は、すべての構成を別フォルダーへ登録する。登録時に1構成だけへ限定するものではなく、QETで図面へ配置するときに実機に合う構成を選ぶ。失敗した構成があっても残りを処理し、完了画面に成功件数と失敗内容を表示する。

リレー・タイマのc接点は、接点番号と端子番号を表示名で区別する。例：`MY4N c接点1（COM:9 / a:5 / b:1）`。COMは共通、aはNO、bはNCの端子番号で、図面上の機器タグとは別の情報。

|---|---|
| リレー・接触器・ブレーカ・スイッチ・センサ等 | `python tools/export_standard_parts.py` / [制御部品](../parts/control/README.md) |
| オムロンDC24V電源 | `python tools/export_power_supply_elements.py` / [電源](../parts/power_supply/omron/README.md) |
| 産業用スイッチングハブ | [ネットワーク部品](../parts/network/README.md) |
| コネクタ | `python tools/export_connector_elements.py` / [コネクタ部品](../parts/connectors/README.md) |

## サンプル

保存済みの製作仕様書は [Sample_qet/manufacturing_spec.qet](../Sample_qet/manufacturing_spec.qet)。A3横1ページの書式確認用で、□／■で選び、数値・その他は記入する。未選択・空欄は未確認。GUIや前付けへの自動追加は未実装。

```console
python tools/make_spec_sample.py
python tools/make_control_sample.py
python tools/make_control_sample.py 回路.qet --horizontal-ladder
```

製作仕様書の既定出力先は `_review/manufacturing_spec/manufacturing_spec.qet`、制御回路は `_review/control_sample/control_sample.qet`。第1引数で出力先を変えられる。PDFは生成しない。

制御回路は押ボタン・リレー・電磁接触器・表示灯を使うDC24V自己保持回路。実端子番号・型式・コイルと接点のQET関連付けを確認できる。QET標準コレクションが必要で、主回路・保護機器の選定や実機動作の保証には使わない。`--horizontal-ladder` は左半ページに収め、P24を左、N24を右に通し、タグ・型式をコイル側、参照表をNの右隣に置く。

## a・b接点の参照表を更新する

QETでコイルと接点を関連付けて保存し、メニューの「a・b接点の参照表を更新」でQETと出力先を選ぶ。

```console
python tools/update_xrefs.py 回路.qet 更新後.qet
```

出力先省略時は `回路_xref.qet` を作る。更新後のファイルをQETで開く。リアルタイム更新や、開いたままの画面への自動反映は行わない。

- コイルの固有ID・関連付け・実端子名からa/bの2行と各極の使用位置を記入する。位置は「頁-行列」（例：`1-C13`）。タグ・型式はコイルの近くへ置き、参照表には重複させない。
- MY/LY等の登録済みリレーは実端子名で極を照合する。c接点の片側だけ配線していればその側だけ、未配線ならa/b両側を掲載する。空いている極は空欄。
- 接点の移動・追加・削除後はQETで保存して再実行する。配線・部品位置・関連付けと参照表の手動位置を維持し、コイルが動いた場合はその移動量だけ参照表も追従する。初回位置は `--dx` / `--dy` で指定できる。
- コイルのタグ表示は標準自動参照と重複させず、更新時に機器番号と同期する。タグ・型式の初回位置はコイル近傍で、その後の手動調整は維持する。
- `--in-place` は元ファイルを更新し、`.qet.bak`（既存なら連番付き）を作る。対象は保存して閉じておき、未保存画面から古い内容で上書きしない。
- 定義が `master` / `coil` のコイルが対象。関連先・実端子の不一致ではエラーにし、出力先を置き換えない。`custom://` の部品はプロジェクトへ取り込んでから使う。

## PDFとプレビュー

PDFはQETの「ファイル > PDFにエクスポート」で書き出し、A3横・余白均等に調整する。プリンタへの直接出力は前提にしない。

```console
python tools/pdf_to_a3.py --drawing 1260x870 図面.pdf
python tools/preview_qet.py 図面.qet 出力フォルダ all
```

`PDF出力.bat`（`tools/qet_export_pdf.py`）はQETの画面を自動操作してPDFを書き出し、A3へ調整する。成功後だけ出力先を置き換えるため、失敗時は既存PDFを保持する。QETを一括終了せず、書き出した図面は開いたまま残す。

簡易PNGの配線はL字の近似表示。最終的な表示はQETのPDFで確認する。

## FREQROLインバータ

シリーズ「FREQROL-E800」または「FREQROL-D800」→種類「インバータ」→形名を選択します。タグ名はINV1などの自由記述、ユニットNo.も入力できます。

1台を1ページの箱型で表示します。電源・制御入力は左、モータ・直流・制御出力は右。接続点は残し、未接続の端子に引出線は描きません。機種に応じた通信コネクタとUSBを表示します。

通信設定は表示・非表示を選択できます。EthernetのEPA/EPBはIP設定、EtherCATのEPCは通信設定を初期表示します。出荷時の短絡片は接続済みで描きます。外部の安全回路は自動配線しません。

### MX-Fの構成と仕様表示

本体図に8/16軸、入力16点DC24V、シンク/ソース出力、出力用外部電源、P1/P2の用途を表示します。IO図ではメーカーの端子記号と割付アドレスを別列に表示します。同じ記号のコモン端子も個別に残します。

構成図の「追加」から対応する専用IOと拡張アダプタを選べます。拡張アダプタは左、専用IOは右に配置します。内蔵IOの次から入力・出力を個別に16進で割り付け、詳細ページにも引き継ぎます。「構成との比較」でタグ・形名・アドレスの不一致を確認できます。

現在の構成選択は本体給電の範囲（右12台、左アナログ4台・通信2台）です。ケーブル接続のFX5増設機器と、増設電源を使う構成はこの選択肢に含めません。機器固有の電源容量・使用条件は資料で確認します。
