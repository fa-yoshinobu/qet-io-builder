# ネットワーク機器

スイッチングハブは機種別JSONで管理し、共通の箱型端子図へ電源・接地・警報・RJ-45を割り当てます。メーカーCADの形状を複製する方式ではありません。

## ミスミの産業用ハブ

登録型式と機種固有の条件は、次の一覧を参照してください。

| シリーズ | 対応一覧 |
|---|---|
| IESH | [対応部品](misumi/iesh/対応部品一覧.md) |
| 金属筐体・Gigabit | [対応部品](misumi/industrial_switch/対応部品一覧.md) |

## 使い方と図の扱い

GUIの「制御部品の書出し・ユーザーコレクション登録」でメーカー・シリーズ・形名を選びます。操作は [使い方](../../docs/使い方.md#部品を書き出す) を参照してください。コマンドからも書き出せます。

```
python tools/export_standard_parts.py IESH-MB208G-R 出力フォルダ
```

- ポート数・端子数に応じた共通枠を使い、接続点は左側にまとめます。枠の寸法は [作図ルール](../../docs/図面の書き方ルール.md#ハブ単体部品の大きさ) に従います。
- RJ-45は既存の共通コネクタ図です。ポート番号ごとにケーブル1本の接続点を作り、内部8ピンへ分解しません。端子台・接地は丸端子です。
- 電源端子、筐体接地ねじ、電源異常リレー接点を区別します。GigaのP-Fail左右は位置を区別する編集上の呼称で、実刻印番号ではありません。
- 登録済みのハブはアンマネージドです。管理IPアドレス・局番の設定欄は作りません。QoS/BSP搭載機種にはDIPの記入用動的テキストを付け、配置後に編集できます。
- IESH-MB205-RのAC24VはV3.0.0に限定した定義です。旧V2.1.2はDC専用として扱い、旧ガイドのAC記載を旧品全体へ適用しません。本体版・実刻印を確認してください。
- IESH-MB208-RはDC12～45V。C2EはDC専用で、樹脂筐体の3極接地端子と金属筐体の2極電源＋接地ねじを区別します。将来予定の仕様変更を現仕様へ反映しません。
- E-IESH-MB100x-T-Rは低電圧AC/DC入力。IESH-MB20xG-Rは二重DC入力とP-Fail接点です。Gigaの接地・DIP有無は未確認で接続点を創作しません。

資料番号と個別の確認状態は各対応一覧を参照してください。

## 定義の追加

既存JSONのcategory=standard_device、component_style=ethernet_switchを使います。power.terminalsに実電源ラベルと用途、groundに接地と接続種別、alarm.terminalsに警報接点、portsに実ポート番号・type=rj45・速度を記録します。DIPはdip_switchesのlabel/function/selectedを記録し、selected=nullは未指定です。資料にない端子番号や内部結線は推測しません。

現在の描画範囲はRJ-45最大8ポート、電源・接地・警報の合計7接続点です。PoE、光/SFP、管理型ハブには対応していません。
