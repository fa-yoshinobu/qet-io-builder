## 登録・書出し

GUIの「制御部品の書出し・ユーザーコレクション登録」から選択し、「QETに登録」または「書き出す…」を使います。操作は [使い方](../../../docs/使い方.md#部品を書き出す) を参照してください。

各シリーズの `power_supply/` に機種JSON、`elements/` にQET用部品を置きます。機種定義から部品を再生成する場合は、リポジトリのフォルダで次を実行します。

```console
python tools/export_power_supply_elements.py parts/power_supply/omron
```

## 図の扱い

入力を左、出力・信号・Ethernetを右にまとめた回路図用の図形です。物理端子の位置は機種定義の `position` を参照してください。同極の端子もそれぞれ接続点を持ち、内部導通を外部配線として描きません。PEは出力0Vと区別します。

不足電圧検出・警報などの信号端子を、負荷給電用の出力として使用しないでください。定格・負荷低減・並列運転・通信設定は、機種の条件に合わせて確認してください。個別の検証範囲は対応一覧を参照してください。

部品の図形は自作で、メーカーCADの複製ではありません。文字コード・資料管理は [開発・保守](../../../docs/開発・保守.md) を参照してください。
