# 三菱電機ユニット対応ゴール

更新日: 2026-10-28

## ゴール

指定された未作成ユニットについて、メーカー公式資料に基づく機種別定義を作成し、GUIで選択して QElectroTech の図面を生成できるようにする。外部配線は、利用者が QET 上で手動仕上げできる状態とする。

## 対象と現在の状態

| 対象 | 状態 | 残り |
|---|---|---:|
| iQ-R | 50機種を追加済み。安全入出力2機種は対象外 | [0機種](iq_r/未作成ユニット一覧.md) |
| iQ-F | 温度入力2機種と通信4機種を追加済み | [0機種](iq_f/未作成ユニット一覧.md) |
| CC-Link リモートIO | 8機種を追加済み | [0機種](cclink/未作成ユニット一覧.md) |
| CC-Link IE リモートIO | 20機種を追加済み | [0機種](cclink_ie/未作成ユニット一覧.md) |
| MELSEC-Q 入出力混合 | QX48Y57、QH42P、QX41Y41P を追加済み | 0機種 |

残りは上記一覧の合計0機種。Qの他の未作成候補は、今回指定された3機種には含めない。これらの候補一覧はメーカーの全製品を網羅したものではない。

## 進め方

- [x] 各機種の公式マニュアルから、端子・ピン番号、電源、コモン、入出力方式、使用条件を確認する。
- [x] 機種別 JSON を適切な部品フォルダに追加し、確認した資料と未確認事項を記録する。
- [x] 必要な生成方式を実装し、GUI の Maker → Series → Unit 選択と構成追加に反映する。
- [x] 入出力回路、アナログ端子、通信・リモートIO の図面を機種に合った構成で生成する。外部配線は手動仕上げでよい。
- [x] 新しい方式・機種に対し、端子、コモン、アドレス、複数ページなど必要な自動検証を行う。
- [x] 代表的な図面を QET で開き、表示、端子接続、ページ構成を確認する。実機での確認は別途扱う。
- [x] 機種を実装するたびに各フォルダの対応済み一覧と未作成一覧を更新する。

ユーザー指定により、安全入出力 RX40NC6S-TS・RY48PT20S-TS は今回の対象外。

## 共通ルール

- 交流専用の入出力ユニットは対象外。QX50 のような直流・交流共用機種は直流用途を対象とする。
- QX48Y57、QH42P、QX41Y41P は混合入出力として扱い、機種ごとに入力・出力のアドレスと端子の違いを確認する。
- `cclink` と `cclink_ie` はリモートIO用。PLCに装着する通信マスタは各PLCシリーズの `network` に置く。QJ61BT11N は `q/network` に置く。
- 電源・本体・増設構成など IO 以外の情報は構成ページにまとめる。IO は別ページにし、通信図は左右半ページに配置できるようにする。
- 通信図には局番・IPアドレス・ディップスイッチのテキスト欄を設ける。使わない項目は空欄でよい。
- 図面は QET の PDF エクスポートを使用し、PDF の余白を確認する。プリンタ固有の余白を前提にしない。
- 資料は文書番号を記載し、PDFへの直リンクは記載しない。
- ルートにファイルやフォルダを増やしすぎず、成果物は既存の用途別フォルダに置く。

## 完了条件

指定された全機種について、機種定義、GUI での選択、適切な図面生成、必要な検証が完了し、一覧に資料と確認状態が記録されていること。安全機能など特別な接続条件がある機種は条件を記録し、未確認の内容を確認済みと表示しない。
