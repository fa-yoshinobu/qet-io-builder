# 制御部品

QET標準記号に型式・実端子・定格・接点構成を割り当てます。多分岐電源や一体形トランスなどは、外部端子をまとめた専用の箱型部品を使います。

## 登録・書出し

メニューの「制御部品の書出し・ユーザーコレクション登録」で部品と構成を選び、「QETに登録」または「書き出す…」を押します。詳しい操作は [使い方](../../docs/使い方.md#部品を書き出す) を参照してください。

```console
python tools/export_standard_parts.py MY4N 出力フォルダ
python tools/export_standard_parts.py SC09XG 出力フォルダ --auxiliary 1a
python tools/export_standard_parts.py "E3Z-D61 2M" 出力フォルダ --configuration light_on
```

補助接点や動作モードが選択式の機器は、実際の構成に合うものを指定します。コイルと接点の関連付け・機器番号・操作電圧は、配置後にQETで設定してください。

QET標準コレクションはインストール先から読み込み、派生部品には元記号の作者・ライセンス表示を保持します。参照先は `--qet-elements` または環境変数 `QET_ELEMENTS_DIR` で変更できます。

## 表記と確認範囲

- MY/LYはリレー本体の実ピン番号。ソケット候補は情報として記録し、ソケットのIEC番号へ自動変換しません。
- LY1の同電位並列ピンは「5/6」のように併記し、標準c接点1極の接続点で表します。物理6ピンを別々の接続点として描く部品ではありません。大電流時のソケット短絡指示は資料間に不一致があり、未確認・自動短絡なしとして扱います。
- 富士の主接点3極・補助NO/NC・A1/A2を区別。極性を持つDCコイルは＋/−を併記します。
- 既存IO図のMY/LY参照極数もこの機種JSONから読み、接点とコイルに本体ピン番号を記入します。project.jsonのrelay_typesによる手動定義も維持します。
- コイル電圧・適合ソケット・完成注文型式は実際の構成に合わせて確認します。検証済みの範囲は各対応一覧を参照してください。

## 定義の追加

参照定義は [standard_symbols.toml](../standard_symbols.toml)。コイル、NO/NC/c接点、主接点3極、端子台、ブレーカ、押ボタン、2位置・3位置セレクタ、表示灯、オンディレイ、サーマル主回路などを使います。センサ、リミット・圧力・フロートスイッチ、ブザー、モータ、電磁弁に加え、ヒューズ、盤内照明・コンセント、ノイズフィルタ、トランス、SPD、電流計・CTにも標準記号を割り当てています。

一般機器の機種JSONはcategoryをstandard_deviceとし、manufacturer/series/device_type/sourceと次のsymbol_bindingsを記載すると、メーカーごとの描画処理を追加せずに共通記号を使えます。

```
"symbol_bindings": [
  {"name": "lamp", "symbol": "lamp",
   "terminals": {"first": ["X1"], "second": ["X2"]}}
]
```

これは書式例で、実在機種の端子確定情報ではありません。役割名はカタログのterminal_rolesに合わせてください。標準内の定格表示を置き換える場合は `standard_text_overrides` に記号名→元の表示文字→置換後文字を記録します。操作位置0/1などの文字は端子番号と区別して保持します。機種が増えても図形は共通で管理します。

## 端子・操作・保護機器

- 端子台本体に固定番号のないXW5T/XW5Gは配線口の位置で示します。記銘板番号・隣接端子への渡りは使用者が指定します。PEは通常信号端子と区別します。
- PYF/PTFソケットは受動部品です。各極を標準端子で表し、外部の実刻印からリレー差込ピンへの対応を表示します。リレーのコイル・接点をソケット内蔵とみなしません。PUの複数配線口と電気端子数を区別します。
- CP30FM-2PはLINE/LOADの左右位置で表示します。数字刻印が未確認のため、QET標準記号の1/2/3/4をメーカー端子番号へ流用しません。
- 東朋FHはホルダの定格と装着ヒューズ容量を別に扱います。ヒューズは別選定・未選択で、ホルダの15/30/60Aをそのままヒューズ定格へ代入しません。
- A22Nは完成押ボタン/セレクタと単品接点ブロックを区別し、照光部はランプと接点を分けます。NO=3–4、NC=1–2、ランプ=X1–X2。機械的に同じ操作部の接点はQETで関連付けてください。
- サーマルは単独設置H・3素子の確定形式です。主回路と95–96 NC/97–98 NOを熱動保護記号で分け、整定範囲と未指定の整定値を表示します。
- H3Yはオンディレイのコイルと限時c接点です。瞬時接点へ置き換えません。13−/14＋はDC使用時だけの条件で、基本形式のコイル電圧・時間は別途選択します。
- S8V-CPは多分岐電子機器として箱型端子図を使います。-VI1/-VI2は内部基準用で負荷電流を流しません。負荷0Vは別コモンから電源0Vへ戻し、ALM1/2も負荷給電用には使いません。4/8分岐とRST/警報接点を保持します。

## センサ・現場機器

- E2E/E3Zの1出力形は裸線の茶＋V・青0V・黒OUTを表示し、コネクタのピン番号は付けません。NPN/PNPは定格文字で区別します。
- E3Zは書き出し時にLight-ON / Dark-ONを選択します。省略・未対応の値はエラーです。選択したモードは別フォルダへ生成します。
- E2E-X2B1D12 2MはSIOモード・NO設定で使用する構成だけ対応します。IO-Link通信の部品ではありません。選択は実機設定の確認を意味しません。
- WLはNO 3–4とNC 1–2の独立回路です。共通端子を持つc接点へ置き換えません。機械連動の扱いは配置後に確認してください。
- IS10は無極性の2線接点です。目盛は下降OFF圧力で、上昇ON圧力は応差を加えます。設定値は使用者が決めます。
- FQは実フロートで、上限ON・下限OFF、上下限間では状態を保持します。61F等のフロートレスとは別です。未確認の芯線色・番号は付けません。
- M2BJの電源接続と音色選択用ジャンパを区別します。SF-PRは国内3リードU/V/Wと接地PEで、PEは機能名です。
- 10-SYは電気コイルだけを表します。ダブルはA/Bを分離し、赤＋・黒−を表示します。空圧回路・LED/保護回路付きの別形式は含みません。

## 開閉・保護機器

- ブレーカは極数に対応する1極・2極・3極の記号を使います。単極の標準記号に入っていた例示定格「C, 16A」は取り除き、機種定義の定格を表示します。
- 数字刻印が未確認の主端子はLINE/LOADと左右位置で表示します。標準記号の汎用1～6をメーカー実端子番号として流用しません。
- サーマルの素子数と主回路極数は別です。3素子用の図を2素子形へ流用しません。整定電流は使用するモータに合わせて指定します。
- サーキットプロテクタと配線用遮断器は別の分類です。定格電流だけで置き換えず、AC/DCの適用・遮断性能・動作特性を各機種資料で確認してください。

三菱S-T10は1a/1b、S-T12/T20・SD-T12/T20は1a1b/2aを選んで生成します。SDはA1＋・A2−。TH-T18KPは3素子の6ヒータ構成で、入力L1/L2/L3は接触器直付けの接続位置を表す機能名です。2素子TH-T18は未対応です。

CP30-BAはねじ端子・付属接点なしの構成に対応し、3極品はAC専用です。NF32-SVFをDC回路で使う場合は、資料の2極使用条件に従ってください。対応する極数・定格電流は各一覧を参照してください。

## その他の選定条件

- タイマは対応する動作モードを選びます。限時接点と瞬時接点を区別し、オンディレイの図を別モードへ流用しません。
- センサの複数出力は、NO/NCと芯線を区別します。IO-Link対応品でも、登録されているSIO設定の図を通信配線へ流用しません。
- 電流計の直結形・CT接続形、CTの変流比を区別します。同じ記号でも、選択した構成に合う部品を使います。
- 電子式リレーモジュールは、外部入力電圧と内部交換用リレーの電圧を区別します。
- ヒューズとホルダは別に選定し、寸法・電流・電圧・許容損失・温度条件を確認します。
- 盤内コンセントのDINレール取付には、別売の取付ベースが必要なものがあります。
- 端子記号で表すソケット・多段端子は、コレクションの表示名に実端子名を付けて区別します。
- 新しい機種定義を起動中のGUIへ反映するには、GUIを再起動してください。
